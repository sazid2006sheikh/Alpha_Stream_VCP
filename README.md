## 🧠 Overview

**Alpha-Speed** enables users to:

* Join or host **real-time video meetings**
* Communicate via **instant chat**
* Experience low-latency communication
* Access the platform directly from the browser (no installation needed)

The application is built with a **clean UI**, **efficient backend communication**, and a **scalable architecture**, making it ideal for real-world usage and further expansion.

## 🏗 System Architecture

```
Client (Browser)
   |
   |  WebRTC (Video / Audio)
   |
Frontend (React)
   |
   |  Socket.IO
   |
Backend (Node + Express)
```

* **WebRTC** handles peer-to-peer video & audio streaming
* **Socket.IO** manages real-time messaging & signaling
* **Backend** acts as a signaling server and message broker

## ⚙ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/alpha-speed.git
cd alpha-speed
```

### 2️⃣ Install Dependencies

#### Frontend

```bash
cd frontend
npm install
npm start
```

#### Backend

```bash
cd backend
npm install
npm run dev
```
